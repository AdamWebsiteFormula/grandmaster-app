# Morning list for Adam (Oct 4, about 5 AM)

Only the steps a person must do. Everything else is done and logged in grandmaster/sops/night-log.md.

1. **Open Upshot.** Press ⌘Space, type Upshot, press Return. This is a new build, so macOS asks again: click **Allow** (or **Always Allow**) for Keychain, the microphone and system audio.
2. **Quick check (2 minutes).**
   - Press ⌘N. Talk for 10 seconds.
   - Press ⌘J. The chat opens.
   - Click **Stop** one time. The recording stops. (New tonight.)
   - Press Esc. The chat closes. A transcript and a summary appear.
   - Click a word in the transcript. The audio plays from there.
   - Press ⌘K. The first row is highlighted. Press Esc. (These animate, so I could not check them while your Mac was locked.)
3. **Record the Loom.** Script: grandmaster/submission/loom-script.md. Transcription is already set (Settings › Transcription shows Upshot / Nova 3 (cloud)). Don't open the old Welcome to Upshot note on camera: it keeps its pre-tonight wording.
