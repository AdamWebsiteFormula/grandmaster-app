## Fine

- README Gatekeeper steps match macOS 15 (Open, then System Settings › Privacy & Security › Open Anyway). The release script ad-hoc signs inside out and the DMG has an Applications link.
- Info.plist purpose strings are branded and plain (microphone, system audio, calendar).
- Notifications are Upshot's own panels, so no macOS notification permission is needed. Granola works the same way ("Granola's own pop-up windows rather than native macOS notifications"). Clicking one brings the main window forward (plugins/notification/src/handler.rs).
- Mic-detected "Take notes" records at once and links a calendar event within 15 minutes (detect-events.ts:367), matching Granola.
- Auto stop waits for the call app to release the mic, rechecks Accessibility and holds through network drops (detect-events.ts:192-330).
- The menu bar has the agenda, New note (records), Settings…, Hide window and Quit completely… with a confirm. "Show events in menu bar" is a toggle.
- Transcription never blocks: Continue works while downloading, and Try again appears only when stalled or failed.
- Light and dark: onboarding uses tokens only (bg-background, bg-card, primary/primary-foreground), so both themes hold. At the 500 px minimum width, the section header text wraps without overflow.
