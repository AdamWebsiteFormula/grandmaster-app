# Red team: Upshot (Oct 2, 2026)

Method: Jack Roberts' "Level 09 Red Team Yourself". I walked the repo as an attacker with read access to the public GitHub repo, focusing on tonight's changes (night-log.md, `git status`, commits since 12:00) and on what ships in the DMG (`~/grandmaster-release/Upshot_1.4.28_aarch64.dmg`, built 17:59). No code was changed. Secret values are redacted everywhere.

Scope notes:
- No backend of our own. `supabase/` is upstream and unused: the release sets no `VITE_SUPABASE_URL`, so `auth/client.ts:78` builds no Supabase client. I skipped RLS.
- The DMG binary has no Sentry DSN and no PostHog key. `release.sh` unsets them, and `plugins/analytics/src/lib.rs:62` makes analytics a no-op. The only Sentry URL in the binary is the SDK's hard-coded connectivity-check URL.
- No `.env` files are in the repo root or `apps/desktop`. The built `dist/` bundle has no JWTs, `phc_` keys or Sentry DSNs.

## Top 3 things to fix today

1. **Block remote images in AI output.** Add an `img` guard (allow only `asset:`, `data:`, `blob:`) to `session/components/streamdown.tsx` and to `chatComponents` in `chat/components/message/normal.tsx`, then add a CSP with that `img-src` to `tauri.conf.json`. This closes the zero-click exfiltration path in every enhanced note and chat answer.
2. **Glaido: ask before bulk reads.** In `settings/developers/glaido.tsx`, move `get_meeting_transcript` and `export_meeting` from `"auto"` to `"ask"`. It's a two-line change to tonight's code.
3. **Approval for chat tools that change data.** Send `apply_session_correction`, `move_meeting_contents` and `move_meetings_to_folder` through the existing pending-edit approval, as `edit_memo` and `edit_summary` already are.
